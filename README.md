# Кудайберген & Назик — свадебное приглашение

Двуязычный (кыргызский / русский) адаптивный сайт на Next.js 15. Дата: **29 ноября 2026**. Место: **Улуу Тоо, ул. Сухэ-Батора 15/1, Бишкек**.

## Локальный запуск

Установите Node.js 20+, затем:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Публикация на Vercel

1. Создайте репозиторий на GitHub и загрузите в него **содержимое этой папки** (файлы `package.json`, `app/` и т. д.).
2. На https://vercel.com/new выберите **Import Git Repository** и ваш репозиторий.
3. Framework Preset: **Next.js**. Root Directory: корень проекта.
4. Нажмите **Deploy**. После сборки получите ссылку вида `имя-проекта.vercel.app`.
5. Для собственного домена: Vercel → Project → Settings → Domains.

## Подключение RSVP (ответы гостей)

**Важно:** без подключения хранилища RSVP не принимает ответы (сервер возвращает ошибку, а не делает вид, что всё сохранил).

1. Создайте пустую таблицу Google Sheets.
2. Откройте **Расширения → Apps Script** и вставьте содержимое файла `google-apps-script.gs`.
3. **Deploy → New deployment → Web app**. Execute as: **Me**, Who has access: **Anyone**. Авторизуйте доступ.
4. Скопируйте URL веб-приложения, заканчивающийся на `/exec`.
5. В Vercel → Project → Settings → Environment Variables добавьте `RSVP_WEBHOOK_URL` с этим URL для Production. Затем **Redeploy**.
6. Отправьте тестовый ответ с сайта; в Google Sheets появится вкладка `RSVP` с именем, присутствием и количеством гостей.

Примечание: форма собирает имена и посещаемость. Предупредите гостей, кто получает эти данные. Публичный Apps Script URL держите в секрете; для масштабного публичного использования добавьте защиту от спама и rate limiting.

## Что настроить перед рассылкой

- **Время свадьбы** ещё не предоставлено. Таймер в `app/page.tsx` сейчас считает до **00:00 29 ноября (Бишкек)**, а не до начала банкета. После уточнения замените `EVENT_DATE` на реальное время (например, `2026-11-29T17:00:00+06:00`).
- **Программа** пока без выдуманных часов; отредактируйте строки `programText` в `COPY`.
- **Фотографии** пока не добавлены: дизайн намеренно типографический. Их можно положить в `public/` и добавить в JSX.
- **Карта** открывает поиск Google Maps по адресу; проверьте правильность метки заведения перед отправкой приглашений.
- **Имена родителей** не указаны, поэтому в тексте приглашение от пары.
